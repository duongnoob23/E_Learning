## Cách sử dụng

1. **Import dữ liệu:** Mỗi file JSON có thể được import trực tiếp vào hệ thống flashcard của bạn.

2. **Cấu trúc dữ liệu:** Mỗi từ vựng bao gồm:
   - `word`: Từ vựng chính
   - `pronunciation`: Phiên âm IPA
   - `meaning_vi`: Nghĩa tiếng Việt
   - `meaning_en`: Nghĩa tiếng Anh (có thể để trống)
   - `part_of_speech`: Loại từ (noun, verb, adjective, adverb)
   - `example_sentence`: Câu ví dụ
   - `example_translation`: Bản dịch câu ví dụ (có thể để trống)
   - `image_url`: URL hình ảnh minh họa
   - `audio_url`: URL audio phát âm

3. **File liên quan:** Mỗi file flashcard có các file tương ứng:
   - `list_XXXXX.json`: File chi tiết với nhiều ví dụ hơn
   - `list_XXXXX-format.json`: File định dạng
   - `list_XXXXX-listen.json`: File luyện nghe
   - `list_XXXXX-matching.json`: File bài tập nối từ
   - `list_XXXXX-quiz.json`: File bài tập quiz
